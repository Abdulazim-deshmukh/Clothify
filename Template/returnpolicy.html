Return policy

A simple policy page for the Clothify demo store.

Simple returns

For this project, returns are intended to be handled manually through customer support. Please contact the store with your order number and the reason for your request.

Before requesting a return

  • Keep your order number available.
  • Make sure the product is unused and in its original condition.
  • Contact support as soon as possible after delivery.

This is a portfolio project, so the policy is intentionally simple and does not include automated return processing.
